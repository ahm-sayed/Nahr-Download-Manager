# Nahr Browser Extension (v1.1)

Official Chrome & Edge integration for **Nahr Download Manager** — intercepts file downloads and displays floating **Download Video / Audio** buttons on YouTube and HTML5 media players across the web.

## Features

1. **YouTube Video, Shorts & Playlist Button** — Shows a floating **Download Video** button on the YouTube player (and an inline button next to YouTube's Share bar) that opens Nahr's standalone **Download File Info** window with full **Quality Selection** (`4K / 1440p / 1080p Full HD / 720p HD / 480p / 360p / Audio Only M4A`) and waits for you to click **Start Download**.
2. **Universal Video & Audio Grabber** — Hover over any `<video>` or `<audio>` player on any website to click **Download Video / Download Audio**, choose quality, and start downloading in Nahr's standalone window.
3. **Automatic Download Interception** — Catches browser file downloads and opens Nahr's standalone confirmation window without popping up the main Nahr manager window.
4. **Alt-Key Bypass** — Hold `Alt` while clicking a link to let the browser download it normally.

## Installation / Reloading

1. Open `chrome://extensions/` (Chrome) or `edge://extensions/` (Edge).
2. Enable **Developer mode**.
3. Click **Load unpacked** and select this `browser-extension` folder (or click the **Reload ↻** icon on the Nahr extension card if already loaded, then refresh open YouTube/web tabs).
